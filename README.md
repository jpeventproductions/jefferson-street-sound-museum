# Jefferson Street Sound Museum — Concept 01

A static, GitHub Pages-ready redesign inspired by historic Jefferson Street, archival print, neighborhood record shops, and the museum’s living collection.

## Interaction notes

- The top navigation hides while scrolling down and returns while scrolling up.
- “Explore” opens a full-screen, keyboard-accessible navigation drawer.
- Story sections fade into view and respect reduced-motion preferences.
- Tour, donation, contact, and social actions route to the museum’s current public pages.
