# Jefferson Street Sound Museum — Concept 02

A multi-page, GitHub Pages-ready redesign inspired by historic Jefferson Street, archival print, neighborhood record shops, and the museum’s living collection.

## Preview

Open `index.html` locally or serve this folder with any static web server.

## Interaction notes

- The top navigation hides while scrolling down and returns while scrolling up.
- “Explore” opens a full-screen, keyboard-accessible navigation drawer.
- The opening screen uses the museum’s vintage poster artwork, with quick links styled as old records.
- Museum, Legacy, Community, Visit, Events, and Founder’s Letter each have a dedicated page.
- Lorenzo Washington’s full portrait is shown without cropping.
- Lorenzo’s achievements are highlighted with links to supporting sources.
- Events and Founder’s Letter are structured for a future private dashboard and Google Calendar connection.
- Story sections fade into view; motion is removed when a visitor prefers reduced motion.
- All tour, donation, contact, and social actions route to the museum’s current public pages.

## GitHub Pages

Publish the repository from the `main` branch and root folder in **Settings → Pages**.
